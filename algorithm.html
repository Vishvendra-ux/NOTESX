Q1MCQ2 MarksGATE CSE 2026 SET-2Dynamic Programming
Consider a table [latex]T[/latex], where the elements [latex]T[i][j], 0 \leq i, j \leq n[/latex], represent the cost of the optimal solutions of different subproblems of a problem that is being solved using a dynamic programming algorithm. The recursive formulation to compute the table entries is as follows:

[latex] \begin{array}{ll} T[0][k]=T[k][0]=1 & \text { for } k=0,1,2, \ldots, n \\ T[i][j]=2 T[i-1][j]+3 T[i][j-1] & \text { for } 1 \leq i, j \leq n \end{array} [/latex]

Consider the following two algorithms to compute entries of [latex]T[/latex]. Assume that for both the algorithms, for all [latex]0 \leq i, j \leq n, T[i][j][/latex] has been initialized to [latex]1[/latex].

[latex]\begin{aligned} &\text{Algorithm } B_1: \\ &\quad \text{For } i = 1,2,\ldots,n \\ &\quad\quad \text{For } j = 1,2,\ldots,n \\ &\quad\quad\quad T[i][j] = 2T[i-1][j] + 3T[i][j-1] \\[6pt]&\text{Algorithm } B_2: \\ &\quad \text{For } s = 2,3,\ldots,2n \\ &\quad\quad \text{For } i = 1,2,\ldots,n \\ &\quad\quad\quad \text{For } j = 1,2,\ldots,n \\ &\quad\quad\quad\quad \text{If } i + j = = s \\ &\quad\quad\quad\quad\quad T[i][j] = 2T[i-1][j] + 3T[i][j-1] \end{aligned}[/latex]

Algorithm [latex]B_{k}, k \in\{1,2\}[/latex] is said to be correct if and only if it calculates the correct values of [latex]T[i][j][/latex], for all [latex]0 \leq i, j \leq n[/latex], (as per the recursive formulation) at the end of the execution of the algorithm [latex]B_{k}[/latex].

Which one of the following statements is true?
  • ABoth algorithms [latex]B_{1}[/latex] and [latex]B_{2}[/latex] are correct
  • BAlgorithm [latex]B_{1}[/latex] is correct, but algorithm [latex]B_{2}[/latex] is incorrect
  • CAlgorithm [latex]B_{2}[/latex] is correct, but algorithm [latex]B_{1}[/latex] is incorrect
  • DBoth algorithms [latex]B_{1}[/latex] and [latex]B_{2}[/latex] are incorrect

[latex]\forall i, j \in\{1, \ldots, n-1\}[/latex] such that [latex]i>j,(A[i+1]-A[i])>(A[j+1]-A[j])[/latex]

Which one of the following gives the worst case time complexity of the fastest algorithm that can be designed for the problem?
  • A[latex]\Theta(n)[/latex]
  • B[latex]\Theta(\log (n))[/latex]
  • C[latex]\Theta(n \log (n))[/latex]
  • D[latex]\Theta\left(n^{2}\right)[/latex]

Each of these spanning trees is represented as a set of edges. The Jaccard coefficient between any two sets is defined as the ratio of the size of the intersection of the two sets to the size of the union of the two sets.

Which one of the following options gives the lowest possible value for the Jaccard coefficient between any two spanning trees of [latex]K_{n}[/latex] ?
  • A[latex]\frac{1}{n}[/latex]
  • B[latex]\frac{1}{2 n-3}[/latex]
  • C[latex]0[/latex]
  • D[latex]\frac{1}{n-1}[/latex]
